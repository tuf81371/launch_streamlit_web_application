# launch_streamlit_web_application
Launch Streamlit Web Application


Streamlit is designed to help data scientists and developers quickly create and share interactive applications. It automatically handles the web interface, state, layout, and reactivity so you can focus on Python code.

Launch Streamlit Application
  st.title()
  st.write()
Launch Streamlit Application - Excel and PDF uploader with button
  st.subheader()
  st.fileuploader()
  st.button()
